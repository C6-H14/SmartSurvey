课题背景与痛点

🎯 什么是空间异常检测？

  • 工业制造中的"找茬"：哪个零件不正常？
  • 3D 点云、RGB-D 多模态数据驱动
  • 自编码重建、记忆库匹配、合成异常扩展……
  • 方法层出不穷，文献量爆发式增长

📚 文献梳理三大痛点

  • 散：跨出版社、跨会议，碎片化严重
  • 乱：缺乏统一横向对比口径
  • 漏：人工翻阅容易遗漏关键证据

🔑 核心技术亮点

  • Inline Scope Binding：evidence_quote 必须在 page_text 中逐字符 containment 验证，3 次自愈失败就地降级但强制保留——100% 杜绝论文静默丢弃
  • XeLaTeX 四遍编译：xelatex→bibtex→xelatex→xelatex 全自动解析 .aux 交叉引用与 .bib 文献数据库，\cite 与 \ref 零报错

PyVis 知识图谱 & 三件套导出

🌐 图形拓扑网络

  • 基于 PyVis + NetworkX 构建
  • 节点 = 论文，边 = 主题/方法关联
  • 节点大小与颜色映射领域字段
  • 渲染为独立 HTML，支持拖拽、缩放、悬浮高亮

🎨 可视化策略

  • 通过 st.components.html 嵌入 Streamlit
  • 懒加载 + 内存渲染适配无头容器
  • 2D/3D 布局透视文献聚类与主题演化

📦 三件套导出

survey_draft.tex + references.bib + matrix_table.tex
