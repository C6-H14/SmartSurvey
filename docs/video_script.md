## 板块一：课题背景（0:00–1:00，约 60 秒）

各位老师、同学大家好，我是来自数学科学学院的钟启帆，学号 PB24010467。今天我汇报的期末项目是 **SmartSurvey——面向空间异常检测与图形可视化的智能文献综述系统**。

首先交代课题背景。空间异常检测是工业制造与机器人感知领域的核心基础能力。它要回答的问题很简单：在一条流水线上，哪个零件不对劲？在机器人抓取前，这块区域的点云是不是正常？

随着深度学习在 3D 点云和 RGB-D 多模态数据上的快速推进，这个领域每年有上百篇新论文发表。但这些论文散落在不同会议和出版社，缺乏统一的横向对比口径。当你想知道"在时延约束下哪篇方法的 F1 更高"，你需要反复翻阅原文，效率极低。

SmartSurvey 的核心动机就是：能不能把一堆异构 PDF 扔进去，自动产出一篇结构完整、证据可追溯的中文综述？

## 板块二：系统架构（1:00–2:15，约 75 秒）

SmartSurvey 采用分层模块架构，以 Python 3.10 和 Streamlit 为骨架，把职责拆成 10 个可独立单测的核心模块，形成"解析 → 提取 → 审查 → 生成"的流水线。

架构上有四个关键层：

第一，**数据接入层**——基于 PyMuPDF 的混合解析管线，采用"核心章节识别 + 兜底页码切片"策略。即使 PDF 没有标准的 Introduction/Conclusion 标题，也能按页兜底抓取。

第二，**核心提取层**——"通用字段 + 领域字段"的双层 Schema 保证跨论文对比的一致口径。最关键的是 **Inline Scope Binding** 零丢纸事实校验：每条 evidence_quote 必须在对应页码被精确包含，3 次自愈失败后就地降级但强制保留，产物行数等于输入 PDF 数。

第三，**图形与安全层**——基于 PyVis + NetworkX 构建 2D/3D 交互拓扑网络。节点表示论文，边表示主题关联，支持拖拽缩放。同时设计了 OS Keyring → .env → 会话内存的三级凭据降级链和网关指数退避重试。

第四，**合成与排版层**——XeLaTeX 物理排版引擎：SSOT 统一导言区由代码硬编码，语法栈扫描器逐字符校验 \$ 奇偶与 begin/end 配对，分章节多阶段合成支持超长文输出。最新的 .tex + .bib 标准分离架构实现了 xelatex→bibtex→xelatex→xelatex 四遍编译配方，\cite 与 \ref 零报错解析。

## 板块三：实际效果与运行演示（2:15–3:30，约 75 秒）

来看实际效果。

系统经 **126 项自动化单元测试全绿验证**，覆盖解析层、证据校验层、凭据安全层、语法扫描层和网络抗抖动层。

典型运行流程：用户在 Streamlit 侧边栏配置 API Key 和综述主题，上传 4 篇空间异常检测论文 PDF，点击"开始生成"。系统依次执行 PDF 解析 → LLM 提取 → 证据审查 → 动态排版，最终产出三件套：survey_draft.tex（全文手稿）、matrix_table.tex（学术对比矩阵）和 references.bib（BibTeX 文献数据库）。

【视频录制指导：此处切入 Streamlit UI 屏幕录制——展示侧边栏输入 → 流式提取进度条 → 动态生成的学术对比矩阵表格 → PyVis 交互图谱拖拽悬浮动画】

部署方面，系统支持三种形态：Windows 本地（run_windows.bat 一键启动）、Docker 容器和 Streamlit Community Cloud。脚本显式锁定 .venv 路径，确保零环境冲突。

## 板块四：未来展望与致谢（3:30–4:30，约 60 秒）

最后说未来展望。我重点提三个方向：

一是**边缘智联计算部署**——将 SmartSurvey 迁移至联宝 EA-B310 等工业边缘平台，结合本地 LLM 推理和轻量化图谱渲染，实现离线文献智能服务。

二是**机械臂空间视觉部署**——将综述提取出的 sensor、latency、deployment_scene 指标对齐到机械臂视觉标定与在线推理链路，实现"文献洞见→工程落地"的正向闭环。

三是**更深度的批判性评述**——引入置信度加权与自动反事实推理，提升综述的批判性学术深度。

以上就是我的期末项目汇报。SmartSurvey 的代码已全部开源在 GitHub，欢迎大家 star 和 PR。

在此我要特别感谢：刘利刚教授的《计算机图形学前沿》精彩课程，翟晓雅老师的细心指导及指出的"可验证最小闭环"等工程要点，陈现敏老师提供的大学生研究计划机会并协助选定空间异常检测研究方向。感谢软件工程学院 AI4SE 课程传授的 Superpowers 技能框架与 Spec-Driven 开发范式，以及测试阶段提供真实论文样例并反馈意见的各位同学。谢谢大家！
